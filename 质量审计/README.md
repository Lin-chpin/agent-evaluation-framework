# 质量审计

本目录记录框架自身的审计结论，不混入业务效果、领域数据或接入方容量问题。状态以可复现检查、源码和公开 CI 为依据，后续审计按职责追加到对应页面。

| 页面 | 范围 |
| --- | --- |
| [运行与恢复](运行与恢复.md) | 测试集输入、case 身份、断点恢复和持久化完整性 |
| [执行与隔离](执行与隔离.md) | 多文件候选、进程边界、容器 Runner 和资源约束 |
| [证据与发布](证据与发布.md) | 已有优点、证据强度、公开表述和仓库成熟度 |

待办仍以 [未完成事项](../路线图/未完成事项.md) 为唯一状态来源。本目录保留缺陷复盘、修复结果、当前边界与公开证据口径，用于展示版本演进，但不复制开发排期。
