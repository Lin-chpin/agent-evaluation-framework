# 证据与发布审计

## 已确认优点

- 核心硬门禁不依赖 LLM，候选生成与晋级决策分离。
- improvement、regression 和 holdout 独立运行，失败、拒绝、接受和回滚均保存。
- 普通 Agent、普通 Skill 和评测 Skill 共用主流程，评测 Skill 另有人工 Gold、歧义状态和独立回归闭环。
- 无密钥证据可以在 Windows 和 Linux 复现，并记录 commit、工作区状态、数据身份和候选决策。
- 项目主要使用 Python 标准库，模块按模型、积木、流程和 CLI 分层。

## 当前证据强度

现有证据足以支持以下结论。

> 框架能够把候选修改放入可审计、可阻断、可回退的评测与演化闭环。

现有证据不支持把项目描述为成熟稳定的生产平台。主要原因是确定性样本规模较小、短 soak 不代表长期资源稳定，私有参考系统也只公开聚合结果。这些是证据边界，不是已知框架正确性缺陷。0.4.0 审计发现的运行完整性问题已在 0.4.1 修复，容器默认隔离也已通过真实 Docker smoke。

## 仓库发布状态

- 当前定位为 `0.4.2 Beta` 和非商业源码公开项目。
- GitHub Actions 已验证 Windows/Linux 机制证据、并发完整性和短 soak，并在 Linux 运行真实 Docker 隔离 smoke。
- 仓库尚无正式 Tag 或 Release；建立 Beta 标签可单独决定，不影响当前源码公开。
- PolyForm Noncommercial 许可不会被 GitHub 识别为常见 OSI 开源许可证，README 必须继续使用“非商业源码公开”而不是“OSI 开源”。
