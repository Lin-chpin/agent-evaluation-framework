# 执行与隔离审计

## 已确认能力

- 单文件和 UTF-8 多文件文本候选在隔离目录中接受或回滚，不覆盖原始基线。
- 进程 Runner 使用显式参数列表、独立工作目录、输出捕获和超时后的进程树终止。
- 容器命令默认禁网、只读挂载工作区、只读根文件系统、移除 capabilities，并限制 CPU、内存和 PID。

## 已确认边界

- 当前目录候选是多文件文本候选，不支持二进制文件、删除、重命名、权限或符号链接语义。
- 普通进程 Runner 会继承宿主环境，stdout 和 stderr 目前没有容量上限，只适合可信适配器或外部隔离后的命令。
- 容器安全仍依赖宿主机 Docker/Podman 和操作系统；该 Runner 不是虚拟机或面向恶意代码的完整沙箱。
- 内置 OpenAI-compatible Evolver 生成完整单文件文本；多文件候选需要自定义生成适配器。

## 已完成验证

Linux GitHub Actions 已执行真实 Docker smoke，实际验证工作区只读、根文件系统只读、网络禁用、`/tmp` 可写和容器内程序输出，不再只检查命令字符串。运行产物保存镜像 RepoDigest、源码提交、返回码和逐项结果。其余边界分别保留，后续按风险与实际需要处理。
