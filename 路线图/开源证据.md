# 公开证据

## 已具备

- `BENCHMARK_RESULTS.md` 集中说明测试设计、结果、限制和可支持结论。
- 无 API Key 的验证脚本运行自动化测试、文本演化、代码演化和两套评测 Skill 演化。
- `evidence/verified-results.json` 保存第三方可复核的数据集哈希、候选决策和三数据集对照。
- 机器证据区分原始 JSONL 文件哈希与规范化 case 清单哈希，并记录框架版本、Git 提交、工作区状态、平台和复现命令。
- GitHub Actions 在 Windows 和 Linux 执行同一证据流程。
- 私有外部参考系统只公开聚合结果，不公开源码、Prompt、业务 case、适配器和内部报告。
- 可追溯重跑在执行前记录框架与目标身份、执行产物、运行环境、模型、数据集和命令，并保存回滚与接受结果。
- 3 次 AI Prompt 演化完整保留接受、协议失败和 holdout 回滚，不只展示最好结果。
- 14B 评测 Skill 实验保留“诊断正确但生成无效候选并被拒绝”的不利结果。
- 14B 固定评测 Skill 的 10-case × 5-round 稳定性实验保存全部50次判断、供应商 token 用量和 Gold 复核后的独立重评分。
- 多文件目录候选测试公开坏候选回滚、好候选接受和基线目录不变。
- Linux CI 使用真实 Docker 验证工作区只读、根文件系统只读、网络禁用和临时目录可写，并保存镜像 RepoDigest 与逐项机器结果。
- 10 秒短周期 soak 保存 51 批次、5100-case、线程回收和 traced memory 结果；Windows/Linux CI 运行 5 秒版本。
- 从公开仓库全新克隆后，wheel 构建、Python 3.12 隔离安装、CLI 与容器 API、自动化测试和独立短 soak 均已复现。

## 证据标准

- 机制证据、AI 模型实验和真实系统集成分开呈现。
- 基线、候选、被测对象版本、评测 Skill 版本、冻结数据集哈希和决策可追踪。
- 公开产物不依赖被 `.gitignore` 排除的本机运行目录。
- 成功结果、异常结果、复现前提和适用范围一起公开。
- 人工审核合成数据只能称为人工审核证据，不能称为真实业务数据。

后续证据工作统一记录在 [未完成事项](未完成事项.md)。

## 发帖时的证据顺序

发帖重点呈现框架机制、接入能力和复现结果，合成数据与真实业务数据分别标注。证据按以下顺序给出：

1. 先链接 `BENCHMARK_RESULTS.md`，让读者看到结论、失败结果和边界。
2. 紧接着给出 `python scripts/verify_evidence.py --output evidence/verified-results.json`，证明核心机制可以无密钥复现。
3. 链接 `evidence/verified-results.json`、`evidence/concurrency-results.json` 和 CI 的 `container-smoke.json` artifact，提供数据集哈希、候选决策、分类指标、并发完整性和真实容器隔离机器记录。
4. 同时呈现两个典型决策结果：14B 生成的无效候选被拒绝；人工审核候选从 25% 提升到 75% 后继续经过 holdout 门禁。
5. 最后链接 GitHub Actions，让 Windows 和 Linux 的第三方运行结果替代本地截图。

建议公开表述：

> 仓库公开保留候选接受、协议失败、无效修改拒绝和 holdout 门禁结果。你可以不配置模型 Key，直接运行验证脚本，检查框架如何隔离测试集、保护回归能力并管理候选晋级。
